# Roadmap

## V1

- Stable JSON receipt schema.
- Markdown renderer for releases, PRs, and handoffs.
- Offline command runner with redacted logs.
- File hash collection for package metadata and lockfiles.
- Fixture-backed tests and smoke receipts.

## Later

- Receipt schema validation command.
- JUnit/TAP import helpers.
- Optional signed receipts.
- Config file support for repeated command sets.
- More redaction presets with custom patterns.
